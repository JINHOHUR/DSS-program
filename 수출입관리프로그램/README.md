# 수출입(외자) 관리 프로그램

RF 전원장치 수출입 업무를 **안건 단위, 0~8단계 순서**로 관리하는 데스크톱 프로그램입니다.
Python 3.8 + Tkinter + SQLite. 외부 의존 없음(엑셀 내보내기만 `openpyxl` 선택).

- 실행: `실행.bat` (Windows). 처음 실행 시 `data/dss_trade.db` 가 생성되고 샘플 안건 2건이 들어갑니다.
- 사용법: `사용설명서.md`
- 설정(회사명·담당자·고객사 목록·신용장 기한 규칙)은 **도구 → 설정 · 기준정보** 에서 입력합니다.
  공개 저장소이므로 기본값은 비워 두었습니다.

## 저장소에 포함하지 않은 것
- `data/` — 실제 업무 데이터(SQLite)
- `spec/` — 내부 업무 규칙 명세, 전환 검토 보고
- 자료방(문서 파일)

이 프로그램은 통합 포털(자바) 아래 웹 모듈로 전환될 예정이며, 그때까지 실무용으로 사용합니다.
