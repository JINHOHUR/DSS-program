# DSS 수출입(외자) 관리 프로그램

「1. 수출입.영업.관리 업무 정리」 엑셀의 **외자(수출입) 업무**를 안건 단위로,
**0 → 8단계 순서대로** 진행하며 관리하는 프로그램입니다.

## 실행

`실행.bat` 더블클릭. (Python 3.8 이상 필요 — 이미 설치되어 있습니다)

## 데이터

`data\dss_trade.db` 한 파일에 모두 들어 있습니다. 이 폴더 밖으로 나가지 않습니다.
이 파일만 복사하면 다른 PC로 그대로 옮겨집니다. 정기 백업은 **파일 → 데이터 백업**.

### 보기 전환 — 같은 목록을 단계별 관점으로

목록 위의 **보기** 버튼으로 열 구성과 합계가 바뀝니다. 안건을 고른 상태는 유지되므로,
보기를 바꿔가며 아래 단계 화면에서 그대로 작업하면 됩니다.

| 보기 | 보이는 열 | 우측 합계 |
|---|---|---|
| **전체** | 최종고객사, 모델, 진행단계, 진척, FCA, 다음 기한, 상태 | 건수 |
| **발주 · 납기 2~3** | P.O 번호·접수일, Debit Note, Offer Sheet, FCA D‑Day, 2·3단계 완료일, 금액 | 금액 합계 |
| **신용장 4** | 개설요청 기한 D‑Day, 개설은행, L/C 번호, 개설일, 선적기한, 만료 D‑Day, 적용규칙(★=고객사 전용) | 개설완료 / 미개설 |
| **선적 · 서류 5~7** | 선적기한, 5·6·7단계 완료일, L/C 만료, 상태, 메모 | 서류 완료 건수 |
| **커미션 8** | 납품금액, 요율, 커미션 금액, 청구서 번호, 청구일, 경과일, 수령일, 상태 | 청구 / 수령 / **미수** |

행 색상 — 🔴 기한 경과 · 🟡 임박 · 🟢 해당 단계 완료 · 회색 완료/취소

### 단계별 진행

**안건을 고르면 지금 해야 할 단계가 자동으로 열립니다.**

- **단계 칩** — 완료는 초록 ✔, 현재는 파랑, 미진행은 회색. 클릭하면 그 단계로 이동
- **단계 카드** — 그 단계에 할 일 설명, 놓치기 쉬운 체크포인트(주황), 저장소 안내
- **입력칸** — 그 단계에 필요한 항목만 나옵니다 (2단계는 P.O, 4단계는 신용장 …)
- **[완료하고 다음 ▶]** — 완료 체크 + 오늘 날짜 + 저장 + 다음 단계로 한 번에.
  마지막 8단계에서 누르면 안건 상태를 `완료` 로 바꿀지 물어봅니다
- **[전체 항목]** 탭 — 모든 항목을 한 화면에서 보고 고칠 때

단계별 입력 항목

| 단계 | 입력 항목 |
|---|---|
| 0. 견적서 요청 접수 | 고객사·담당자, 최종고객사, 사이트, 모델/품명, 수량, 구분, 필요시기 |
| 1. 교산에 견적 전송 | 금액, 통화 |
| 2. 발주서(P.O) 접수 | P.O 번호·접수일, 금액, 통화 |
| 3. 교산 주문·납기 관리 | Debit Note, Offer Sheet 번호, **FCA** |
| 4. 신용장(L/C) 개설 | 개설요청 안내일, 개설은행, L/C 번호, 개설일, Latest shipment, Expiry date, Amend |
| 5. 선적서류 수령 | (완료일 · 메모) |
| 6. 선적서류 발송 | (완료일 · 메모) |
| 7. 원산지증명서(C/O) | (완료일 · 메모) |
| 8. 커미션 청구·수령 | 요율, 금액, 청구서 번호, 청구일, 수령일 |

### 자료 폴더 연결

안건마다 자료방 폴더를 한 번 지정해두면(**[폴더 지정]**), 각 단계의
**[📁 자료 폴더 열기]** 가 그 단계에 맞는 하위 폴더로 바로 이동합니다.

| 단계 | 열리는 폴더 |
|---|---|
| 0·1 | `02_견적` |
| 2 | `03_PO` |
| 3 | `04_Offer sheet` |
| 4 | `05_신용장` |
| 5·6·7 | `06_선적` |
| 8 | `07_정산` |

폴더를 지정하지 않았으면 자료방 최상위의 해당 분류(`05. 수주_PO` 등)로 갑니다.

## 대시보드

요약 카드 4개(진행중 / 7일 내 임박 / 기한 경과 / 커미션 미수령) + 기한 알림 + 고객사별 현황.
`진행중 안건` 카드는 [안건 관리 → 전체] 로, `커미션 미수령` 카드는 [안건 관리 → 커미션 8] 로
바로 이동합니다. 알림 줄을 더블클릭하면 해당 안건이 열립니다.

| 알림 | 기준 |
|---|---|
| L/C 개설요청 기한 | FCA − 7일 · 4단계 미완료 시 |
| FCA (선적예정) | FCA 당일 · 5단계 미완료 시 |
| Latest shipment | 선적기한 초과 시 Amend 필요 |
| L/C 유효기간 만료 | Expiry date · 6단계 미완료 시 |
| 커미션 미청구 | C/O(7단계) 완료 + 청구일 공란 |
| 커미션 미수령 | 청구 후 30일 경과 |

## 자료방

`Desktop\1. 수출_수입_영업관리\자료방` 을 프로그램 안에서 탐색·관리합니다.

- 상단 **분류 버튼** — `01. 프로젝트별 관리` ~ `11. 계약 및 정산`, `외자관리`
- 왼쪽 **폴더 트리**, 오른쪽 **목록**(폴더가 위로 정렬)
- **파일 더블클릭 → 기본 프로그램으로 바로 열림**
- **파일 검색** — 현재 폴더 이하 전체를 이름으로 검색, `위치` 열에 상대경로 표시

### 서류 올리기 · 관리 (둘째 줄 버튼)

| 버튼 | 동작 |
|---|---|
| **＋ 파일 올리기** | 파일을 골라 **현재 폴더로 복사**. 여러 개 가능, 원본은 그대로 |
| **새 폴더** | 현재 폴더 안에 하위 폴더 생성 |
| **이름 변경** | 선택 항목 이름 변경 (확장자 제외하고 선택된 상태로 열림) |
| **삭제** | **Windows 휴지통**으로 이동 — 복원 가능 |

**같은 이름이 있으면** `이름 바꿔 저장`(권장) / `덮어쓰기` / `건너뛰기` / `취소` 중 선택.
여러 개일 때 *남은 N개에도 같은 방식 적용* 을 체크하면 한 번만 물어봅니다.
자료방 **최상위**에 바로 올리려 하면 한 번 더 확인합니다.

## 업무 플로우 — 자유롭게 그리는 플로우차트

박스를 **끌어서 원하는 자리에 놓고**, 화살표를 **직접 이어서** 우리 회사 업무 흐름대로
그릴 수 있습니다. 항목을 클릭하면 그 단계의 자료가 바로 뜹니다.

```
[＋ 항목 추가][수정][삭제] │ [🔗 연결 그리기][자동 정렬][기본값 복원]
                    [🔍 화면에 맞추기] [－] 100% [＋] [상세 숨기기] ← 오른쪽
┌────────────────────────────────────┬──────────────────────┐
│ ┃0.견적요청┃ ─→ ┃1.교산견적┃         │ 4. 신용장(L/C) 개설  │
│      │              │              │ 교산제작소가 Offer…  │
│      └──→ ◇고객승인?◇ ──승인──→     │ ✔ 개설요청서는 선적… │
│              │반려                  │ 저장소 : 신용장 폴더 │
│              ↓                      │ 📁 자료방 › 05_신용장 │
│         ┃2.P.O접수┃ ─→ ┃4.신용장 ①┃ │ ── 관련 자료 ────  │
│                                     │ 📁 001_외자견적서    │
│  ┃ ┃ 사각형(작업)  ◇ ◇ 마름모(판단)  │   견적서_ICD.pdf    │
│  ◯ 타원(시작·종료)                   │ ── 진행중 안건 ──  │
│  ① 원 안 숫자 = 그 단계 진행중 안건 수 │ 2026-001 L/C요청 D-5│

```

### 한눈에 보기

| 조작 | 동작 |
|---|---|
| **[🔍 화면에 맞추기]** | 모든 항목이 화면에 들어오도록 배율을 자동 조정합니다. 화면을 열면 처음에 자동으로 한 번 실행됩니다 |
| **[－] / [＋]** | 30% ~ 200% 축소·확대. 가운데에 현재 배율이 표시됩니다 |
| **Ctrl + 마우스 휠** | 확대·축소 |
| **Shift + 휠** | 좌우 스크롤 (그냥 휠은 위아래) |
| **[상세 숨기기]** | 오른쪽 자료 패널을 접어 플로우차트를 화면 전체로 넓게 봅니다. 한 번 더 누르면 되돌아옵니다 |

배율이 **62% 아래로 내려가면 박스에 제목만** 표시되어, 항목이 많아도 전체 구조가
한눈에 들어옵니다. 축소한 상태에서도 클릭·드래그·연결은 그대로 됩니다.

### 그리기

| 조작 | 동작 |
|---|---|
| **박스를 끌기** | 원하는 위치로 자유롭게 이동 (5px 단위로 정렬, 위치는 바로 저장) |
| **[🔗 연결 그리기]** | 켠 뒤 → **시작 박스 클릭 → 도착 박스 클릭** 이면 화살표가 생깁니다. `Esc` 또는 빈 곳 클릭으로 해제 |
| **연결선 클릭** | 선이 파랗게 선택됩니다. **[삭제]** 로 그 선만 지울 수 있습니다 |
| **연결선 더블클릭** | 선 위에 글자를 넣습니다 (예: `승인`, `반려`, `재견적`) |
| **박스 더블클릭** | 항목 내용 수정 |
| **[자동 정렬]** | 순서대로 격자 배치로 되돌립니다 |
| **[기본값 복원]** | 엑셀 기준 0~8단계 + 순서 연결선으로 초기화 |

화살표는 도형 모양에 맞춰 테두리에 정확히 붙고, 박스를 옮기면 따라 움직입니다.

### 도형과 색

항목 수정 창에서 고릅니다.

| 도형 | 용도 |
|---|---|
| **사각형** | 작업 단계 (기본) |
| **타원** | 시작 · 종료 |
| **마름모** | 판단 · 분기 |

색은 `자동(단계색)` 이면 연결 단계에 따라 자동으로 정해지고,
파랑 / 보라 / 주황 / 초록 / 청록 / 빨강 / 회색 중에서 직접 고를 수도 있습니다.

### 항목을 클릭하면

- **설명 · 체크포인트 · 저장소** 가 오른쪽에 표시됩니다
- **관련 자료** — 그 단계의 자료방 폴더 안 파일 목록.
  **더블클릭하면 파일이 바로 열립니다** (폴더는 자료방 화면으로 이동)
- **이 단계 진행중 안건** — 지금 그 단계에 머물러 있는 안건. 더블클릭하면 안건이 열립니다
- **[📁 자료방에서 열기]** — 자료방 화면에서 그 폴더를 엽니다

박스 안 원의 숫자는 **지금 그 단계에 있는 진행중 안건 수** 입니다.

### 항목 편집 내용

항목 이름 / 설명 / 체크포인트 / 저장소 안내문 / **도형 · 색** /
**자료방 폴더**(찾아보기) / **연결 단계**(0~8 또는 연결 안 함)

- **자료방 폴더** 를 지정하면 그 폴더의 파일이 [관련 자료]에 뜹니다.
  비워두면 연결 단계의 기본 폴더를 씁니다.
- **연결 단계** 를 지정하면 그 단계의 진행중 안건 수와 목록이 함께 표시됩니다.
  업무 안내용 항목(예: 사내교육, 전시회, 판단 분기)은 `(연결 안 함)` 으로 두면 됩니다.

박스 위치 · 도형 · 색 · 연결선은 모두 `data\dss_trade.db` 에 저장되므로
프로그램을 다시 켜도 그대로 유지됩니다.

| 고객사 | Latest shipment | Expiry date |
|---|---|---|
| 기본 | FCA **+ 14일 (2주)** | FCA **+ 28일 (4주)** |
| (고객사별 예외) | 예: FCA **+ 7일** | 예: FCA **+ 14일** |

- FCA를 입력하면 두 칸이 자동으로 채워집니다.
- **FCA를 나중에 바꾸면** 신용장 기한도 따라서 다시 계산됩니다.
  단, 기한을 직접 손대서 규칙과 다른 값이 들어 있으면 **덮어쓸지 물어봅니다.**
- **[기한 자동계산]** 버튼은 언제나 규칙대로 다시 계산합니다.
- 개설요청서 수령 기한 = **FCA − 7일**
- 위 숫자는 모두 [도구 → 설정]에서 바꿀 수 있습니다.

날짜는 `20261108` / `2026.11.8` / `2026/11/08` 무엇으로 넣어도 `2026-11-08` 로 정리됩니다.
금액은 저장 시 자동으로 천 단위 콤마가 붙습니다.
