# template/

이 폴더에 **원본 견적서 양식 파일**을 두어야 합니다.

```
template/견적서.xls
```

## 저장소에 포함되지 않는 이유

원본 양식에는 아래와 같은 회사 고유 정보가 들어 있어 `.gitignore` 로 제외했습니다.

* 법인 직인 이미지
* 회사 로고
* 사업자등록번호, 대표자 성명
* 은행 계좌번호
* 회사 주소·전화·팩스

## 요구 조건

이 프로그램은 **BIFF8 형식의 `.xls`** 를 직접 편집합니다. 다음을 만족해야 합니다.

* OLE2/CFB 컨테이너, 512바이트 섹터 (Excel 97~2003 `.xls`)
* 워크시트 1개
* SST 가 CONTINUE 로 분할되어 있지 않을 것

`.xlsx` 는 지원하지 않습니다.

## 양식이 다를 때

셀 주소·품목 영역·서식 인덱스는 전부 `config/mapping.json` 에 있습니다.
다른 양식을 쓰려면 그 파일의 값을 본인 양식에 맞게 고치면 됩니다.
현재 값은 아래 구조를 전제로 합니다.

| 항목 | 위치 |
|---|---|
| 상단 정보 (발행일자·발행번호·공급처·품명 등) | `C12` ~ `C21` |
| 품목 표 | `B23:H58` (번호·품명·규격·단위·수량·단가·금액) |
| 공급가액 / 부가세 / 합계 | `H60` / `H61` / `H62` |

양식을 분석해 매핑을 다시 잡으려면 `tests/test_roundtrip.py` 를 먼저 돌려
엔진이 그 파일을 무손실로 읽고 쓰는지 확인하는 것이 좋습니다.
